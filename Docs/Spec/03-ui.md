# Hearth – UI / UX spec (iOS & iPadOS)

Clean-room behavioural spec. Native SwiftUI, iOS 26 design language (Liquid Glass, `.glassEffect`, `tabViewBottomAccessory`, `tabBarMinimizeBehavior(.onScrollDown)`), iPhone + iPad, multi-window on iPad, Mac "Designed for iPad" compatible. All user-visible strings via String Catalog (English source, German translation).

## 1. Root routing
1. Connections loading → loading view (pulsing SF symbol + "Loading…").
2. No connections → Welcome / onboarding.
3. Offline mode → Offline view (downloaded content only).
4. Otherwise → main tab/sidebar UI.
App-wide: tint color from settings, forced color scheme option, sensory feedback (success/error haptics), create-bookmark alert, sheet & warning-alert coordinators.

## 2. Navigation
### iPhone (`TabView` with `.sidebarAdaptable`; on compact = tab bar)
- Tab bar shows the **current library's tabs** (max 5, configurable) + **Search** tab (`Tab(role: .search)`).
- Defaults: audiobook library → Home, Library, Series, Authors; podcast library → Home, Latest, Library. Available: Home, Library, Series, Authors, Narrators, Bookmarks, Collections, Playlists, Downloaded, Latest (podcasts only), Statistics.
- **Library picker** (toolbar on Home + Search): libraries grouped by server (icon by type), "Pinned tabs" mode, Settings, Offline mode toggle, connection status ("N offline – retry"), "Customize tabs".
- Pinned tabs: user-built mixed tabs from any library (labelled with library name).
- Restore last tab on launch.
- Connection failure → error view with "Going offline in N s" countdown (7 s) + retry; all servers fail → auto offline.
- External navigation (Spotlight, Siri, widget, URL, Handoff) switches to a suitable library tab, waits for sync, pushes the item.
- Mini player as `tabViewBottomAccessory` (glass pill): cover, two-line title (book + chapter / date + episode), skip back (hidden when tab bar minimized via `tabViewBottomAccessoryPlacement`), play/pause, buffering spinner. Nothing playing but last item known → "Resume" pill. Tap → full player; long-press → context menu (mark finished, stop, add to…, go to item/author/series/podcast).

### iPad (regular width)
- Same `TabView(.sidebarAdaptable)` → sidebar: top "Listen Now" + "Listened today" gauge row, "Search", then a `TabSection` per server → per library with its tabs (all available tabs, customizable via `tabViewCustomization`). Bottom: Settings, Offline toggle.
- Player: bottom accessory bar (cover, title, speed, back, play/pause, forward, sleep timer) + full screen player; landscape full player = 2 columns (cover+controls | queue/chapters panel).
- Multiple windows (`WindowGroup` + `openWindow(value: ItemIdentifier)` to open an item in a new window), keyboard shortcuts (Space play/pause, ←/→ skip, ⌘F search, ⌘[ ] chapters, ⌘B bookmark, ⌘1…⌘9 tabs), pointer hover effects, drag & drop items into playlists/queue (Transferable).

## 3. Screens
**Audiobook Home**: server personalized shelves as horizontal rows (titles localized for known ids: continue-listening, continue-series, recently-added, recent-series, listen-again, discover, newest-authors, …; unknown → server label); >5 items → chevron opens full grid. Optional authors row (setting `showAuthorsRow`), hide Discover (`hideDiscoverRow`), local "Downloaded" row. Filter hidden-from-continue-listening. Toolbar: Listened-today gauge button (opens Listen Now sheet) + library picker. Pull to refresh.
**Podcast Home**: continue-listening episodes as featured carousel cards (tall, blurred cover background, gradient, date/title/2-line description, glass play pill); other episode rows as 2-row horizontal grids; podcast rows with "N unplayed".
**Library (audiobooks)**: optional shortcut rows (Series, Authors, Narrators, Bookmarks, Collections, Playlists, Downloaded – configurable). Grid/list, infinite scroll (pages of 100), count footer. Genre/tag filter menu, options menu: display mode, progress filter (in progress / finished / not finished / not started) + Downloaded toggle, sort (Title, Author, Published, Added, Duration; tap selected flips direction), "Group books in series" toggle, Customize. Defaults: Added desc, list → Hearth default grid. Series groups render as cover collage (grid) / fanned stack (list); single-entry groups optionally replaced by the book. Settings synced via iCloud KVS (`NSUbiquitousKeyValueStore`).
**Library (podcasts)**: grid (min 160 iPhone / 200 iPad) with unplayed badge or list; sort Title/Author/Episode count/Added.
**Series**: grid (collage 1 / 2–3 diagonal / 2×2) or list (fanned covers, "N books"); sort Name/Books/Added/Duration.
**Authors**: round avatars, "N books"; sort First Last/Last First/Books/Added. **Narrators**: same without images; sort Name/Books.
**Bookmarks**: books with bookmarks + count. **Collections/Playlists**: 68 pt image (cover or 2×2 mosaic), name, count. **Downloaded**: episodes then books. **Latest** (podcasts): 20 recent episodes.
**Search** (`.searchable`, 0.3 s debounce): scopes "This library" / "Everywhere"; sections: Audiobooks, Podcasts, Episodes, Series, Authors, Narrators; ranked by similarity. Search suggestions from recent searches.
**Statistics** (Hearth addition, replaces stub): today vs goal ring, last 7/30 days bar chart (Swift Charts) from `api/me/listening-stats`, total time, top items, streak.

### Shared item behaviours
- Context menu: [Share | Add to… | Download] control group; Play; Play next; Add to queue; Mark finished/unfinished ("Finished <relative>"); Reset progress; Hide from Continue Listening; links View audiobook/Author(s)/Narrator(s)/Series or View episode/podcast. Preview: large cover+title+authors+narrators (book) or cover/date/duration/title/description (episode).
- Swipe leading: Play (tint), Add to queue (accent). Trailing: Download/Remove (blue/red), Finished/Unfinished (green/orange).
- Accessibility labels/values ("Audiobook: X", "42 %, downloaded"), magic tap plays.
- Cover status overlay (grid): corner triangle with progress ring (or % text if `showProgressPercent`), checkmark finished, download progress, small arrow if downloaded but not started.
- Audiobook row: cover 80 pt (tap plays), bold title, "authors • narrators" (or series when on author page), small-caps line "#seq • year • Finished / remaining / duration • 🅴 🅰".
- Episode row: cover 92 pt (hidden on podcast page), title (2 lines), description (1–3 lines), action line: pill play button with inline progress ("Play again"/remaining/duration), trailer/bonus icon, date, download state, ellipsis menu.
- Compact row (search, listen now, collections): caption (date/duration), title, subtitle, trailing progress ring / download ring / unplayed count.

## 4. Detail screens
Shared hero header: transparent nav bar until scrolled past header, then compact centered title; back-button history menu (system); pull to refresh reloads item; dominant cover color used for header gradients and play button tint (`ImageColorExtractor`, cached). `NSUserActivity` for Handoff.
- **Audiobook**: iPhone: big cover with shadow, series link(s) "Name #n" (menu if several), serif title (4 lines), subtitle, author link(s), info line (🅴 🅰, "Read by …", duration), large glass play pill (progress-filled, "Listen / Resume / Listen again • 3h 12m left", long-press menu). iPad: cover left (≤400 pt), info right. Body: Description (HTML → AttributedString, links tappable), collapsible sections: Bookmarks (tap plays from there, swipe delete, edit note), Chapters (>1; past dimmed, current bold, tap plays from chapter), Timeline (total listening time, last played, session list from `listening-sessions`, released marker), Documents (PDFs), Details (publisher, language, ISBN/ASIN, genres, tags, added date, size). Bottom rows: "More in series X", "More by author X", "Read by narrator X". Toolbar: Read (PDF, menu if several), Download button with progress ring (tap cancels), ellipsis menu (share/add to/download, play/queue, finished/reset, links, Configure).
- **PDF viewer**: PDFKit full screen, book display mode, Done, share.
- **Podcast**: full-bleed gradient from dominant color, adaptive text color; cover 240 pt, name, authors, play-latest/next button, 3-line description (tap → full sheet), stats line (# episodes, explicit, episodic/serial, genres). Episodes section: season menu (≥2 seasons), first 15 episodes with filter/sort, "All Episodes →". Info footer. Toolbar: Configure, options (filter default Not finished, downloaded toggle, sort Name/Index/Release date/Duration; persisted per podcast; default from settings).
- **All Episodes**: season capsule picker, search field, select mode with bulk actions (Add to queue, Download, Remove download, Mark finished/unfinished).
- **Episode**: gradient header, cover 180 pt, "date • duration", title, podcast link, play button, trailer/bonus label. Description with tappable timestamps. Info list (podcast, author, episode #, season, release date/time, editable episode type menu → PATCH). Timeline. Toolbar: download, ellipsis.
- **Series**: fanned covers (up to 5), serif title, play first unfinished, books grid/list with "#sequence". Toolbar: Configure, options.
- **Author / Narrator**: avatar 120 pt, name, description (3 lines → sheet). Authors: Series section + Audiobooks (sorted by release asc). Narrators: books. Display mode/filter options.
- **Collection / Playlist**: description, play first unfinished, items (rows). Toolbar: Edit (sheet: name, description, reorder/delete items), menu: Play, Add all to queue, Configure, Create playlist from collection, Delete.
- **Add to… sheet**: Collections (books only) + Playlists sections, each with "+ New…" (name alert → create with item → open), already-containing collections disabled.
- **Configure sheet** (audiobook, series, podcast, collection, playlist): playback speed, auto sleep timer, up-next strategy (series/podcast), allow suggestions, auto-download rule (Disabled, 1,2,3,4,5,10 items, podcasts: last 24 h / week / 2 weeks / month, All). Non-default values bold.

## 5. Player
- **Full player (iPhone)**: presented as full-screen cover with zoom/matched transition from mini player (`.navigationTransition(.zoom)` / `matchedTransitionSource`), interactive drag-to-dismiss. Layout: grabber; square cover (shrinks when paused, spring); title block (date if episode, title, authors; tap → menu) + bookmark button (books; tap = note prompt, long-press = quick bookmark); chapter scrubber (thin bar, grows while dragging, acceleration, labels elapsed / chapter title or remaining-at-rate / duration ↔ −remaining toggle); transport (skip back w/ interval icon `gobackward.15`, large play/pause, skip forward; tap combining badge; long-press = chapter start / next chapter; buffering shows animated symbol); bottom slider: volume (`MPVolumeView`-backed) or total progress; action row: Speed ("1.3×", tap cycles, menu presets + −/+), Sleep timer (moon; shows remaining; menu), AirPlay (`AVRoutePickerView` with route icon), Queue toggle.
- **Queue/Chapters panel** (toggle in full player; cover shrinks to 72 pt thumbnail): Bookmarks, Chapters (or episode description), Queue (Clear; reorder/delete; swipes), Up Next (source subtitle, Clear, promote). TipKit tip: "Configure Up Next in series & podcast settings".
- **Lyrics-like chapter view** optional: none.
- Auto-open player when a new item starts (unless stopped < 10 s ago); close on navigation.
- iPad: bottom bar + full screen 2-column landscape / centered portrait (max 600 pt).

## 6. Onboarding & connections
- **Welcome**: app icon, "Welcome to Hearth", short feature bullets, "Add server" prominent glass button, footer links (License, Privacy, Source code on GitHub).
- **Add connection** form: server URL (URL keyboard, verify on return; "http(s)://host(:port)(/path)" hint) → status check → green "Server version x" (orange outdated warning < 2.26.0). Collapsible custom headers (Key/Value, add/remove). Self-signed cert prompt ("Trust certificate SHA-256 …?"). Optional client certificate import (.p12 via `fileImporter` + passphrase). Known servers quick-fill. Auth method picker (password / SSO) → username+password → "Sign in"; OpenID auto-starts (ASWebAuthenticationSession, PKCE, `hearth://oauth`; footer: add `hearth://oauth` to ABS allowed redirect URIs).
- **Manage connections** (Settings): list (red if offline), detail (user, server, version, legacy-auth hint, edit headers, re-authorize, remove), add, remove all. Re-login sheet opens automatically on unauthorized.

## 7. Settings (in-app; no Settings.bundle needed, but provide one for discoverability? → No, all in-app)
Sections: Connections; Appearance (tint color: Hearth (warm amber, default), Yellow, Red, Pink, Purple, Blue, Teal, Mint, Green, Graphite; each with paired accent; color scheme System/Light/Dark; serif titles; progress as %; high quality images); Playback (speed presets & default & steps; skip intervals; smart rewind; chapter-relative progress; lock seek bar; total progress instead of volume; next/previous = chapters; generate up next); Sleep timer (presets, extend settings, fade, shake, play-to-extend); Library (group books in series, show single-entry series, show authors row, hide discover, default episode order, tabs customization, pinned tabs); Downloads (cellular, remove finished, auto-download master, listen now auto-download, configurations list, storage usage, purge downloads/cache); CarPlay (listen now tab, library tabs ordered, other libraries); Daily goal; Siri & Shortcuts (link to Shortcuts); Support (GitHub issues, export logs via `OSLogStore` → zip/share, purge Spotlight index, diagnostics: version, build, schema, last auto-download/spotlight run); About (license MIT, privacy, acknowledgements, source code).

## 8. Listen Now, goal, offline, states
- Listened-today gauge button (¾ ring in tint; minutes; goal) → Listen Now sheet (zoom transition; compact rows across all libraries; tap plays & dismisses; "Auto-download Listen Now" toggle). Long-press: goal −/+.
- Offline view: downloaded audiobooks (sorted by progress), sections per downloaded podcast, "Go online", Settings, Listen Now; mini player.
- Empty: `ContentUnavailableView` "No items" / search uses `.search`. Error: "Content unavailable — make sure Hearth can reach your server" + Retry. Loading: pulsing symbol.
- Warning alerts: play while downloading; download while playing; remove download while playing; remove auto-downloaded item (Cancel / Remove rule / Proceed).
- TipKit tips: Up next config, long-press skip, bookmark long-press.
- What's New sheet keyed by version.
- Haptics: `.sensoryFeedback` on actions.

## 9. Downloads UX
Toolbar/context/swipe/bulk; max 4 parallel, background; weighted progress ring (tap cancels). Auto-download rules (see API spec 4.6) with configurations list in settings. Cellular & remove-finished settings. Downloaded tab, Home downloaded row, Offline view, CarPlay.

## 10. Localization
String Catalogs (`Localizable.xcstrings`) per target/module, English + German, plurals via catalog variations. App Shortcuts phrases in `AppShortcuts.xcstrings`. InfoPlist strings catalog.
